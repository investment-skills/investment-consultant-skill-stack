# Evidence, Gates, and Red Flags

## Evidence classes

- A: audited or independently verifiable.
- B: management reporting with source support.
- C: founder-provided unsupported data.
- D: analyst assumption or external benchmark.

Material metrics should carry an evidence class when practical. Forecast assumptions should also be tagged historical-derived, founder-provided, external benchmark, or analyst assumption.

## Gate 1 — Minimum analyzability

Pass only when stage, business model, core revenue logic, and capital ask are sufficiently known. If failed, list what is missing, why it matters, blocked analyses, and minimum substitute data.

## Gate 2 — Economic coherence

Classify unit economics as:

- Viable
- Viable with scaling dependency
- Needs improvement
- Economically inconsistent / insufficient data

Do not confuse missing data with negative performance.

## Gate 3 — Model reliability

Classify spreadsheet models as:

- Passed
- Passed with non-material warnings
- Failed — remediation required

A failed model is not a reliable primary valuation/returns basis.

## Conflicting evidence

Do not choose silently. Record:

1. Source A and value.
2. Source B and value.
3. Difference and materiality.
4. Temporary working assumption only if necessary.
5. Reconciliation question and blocked outputs.

Material unresolved conflicts block a final IC recommendation unless explicitly risk-rated and waived by the decision maker.

## Red-flag overrides

Red flags can override arithmetic readiness scores, including unreconciled ownership, undisclosed material liabilities, irreconcilable customer/revenue metrics, critical IP ownership gaps, severe unmitigated concentration, cash balance inconsistent with actual liquidity, licensing/regulatory prohibition, and materially inconsistent founder financials.

## Specialist dependency failure

If a dependency is unavailable, name the missing capability and downstream consequence. Use only explicit fallback logic. Never claim a specialist result exists when it was not produced.
